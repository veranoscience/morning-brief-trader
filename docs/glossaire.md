# Glossaire trading

Document de référence chargé dans le Projet Claude, pour que l'assistant et les utilisateurs métier parlent la même langue.

| Terme | Définition |
|---|---|
| **Position longue (long)** | Détention d'un titre ; gagne quand le cours monte. Quantité positive. |
| **Position courte (short)** | Vente d'un titre emprunté ; gagne quand le cours baisse. Quantité négative. |
| **Couverture (hedge)** | Position prise pour réduire un risque, ex. short SPY pour amortir une baisse du marché. |
| **Valeur de marché** | Quantité × cours de clôture. Négative pour un short. |
| **Exposition brute** | Somme des valeurs de marché en valeur absolue : mesure la taille totale du portefeuille. |
| **Exposition nette** | Somme des valeurs de marché avec leur signe : mesure le pari directionnel. |
| **P&L du jour** | Quantité × (clôture du jour − clôture de la veille). |
| **P&L latent** | Quantité × (clôture du jour − prix moyen d'entrée) : gain ou perte non encore réalisé. |
| **Prix moyen d'entrée** | Prix moyen pondéré auquel la position a été constituée. |
| **Concentration** | Part d'une seule ligne dans l'exposition brute. |
| **Limite** | Seuil de risque fixé par le risk management pour un trader ou un desk. |
| **Utilisation** | Mesure ÷ limite, en %. |
| **Front / Middle / Back office** | Front : traders et vente. Middle : risque, contrôle, P&L. Back : règlement-livraison, comptabilité. |
| **Clôture** | Dernier cours de la séance. |
| **Séance** | Journée de bourse (jours ouvrés). |
